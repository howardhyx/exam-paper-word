# 多学科试卷编写

把用户的考试要求落实为可核对的命题蓝图、逐题命题方案和两份可打印的 Word 文档。默认输出“试题卷.docx”和“答案与评分标准.docx”，前者包含大题作答空间，后者包含参考解答及采分点。题目正文、解答、图表和采分点使用同一份结构化题目记录，避免两卷分别编写造成不一致。

## 学科与任务边界

- 支持任意学科与跨学科试卷。学科、学段、课程和题型均由当前任务决定；全国卷只是默认的视觉风格参考，不自动限定为高中、数学或某一年的题型结构。
- 根据学科处理阅读、写作、论述、语言应用、史料、地图、实验、计算、证明、艺术鉴赏、专业实践等任务。这些是适配示例，不是允许学科或题型的白名单。
- 用户只要求讨论、命题蓝图、个别题目或修改某一步时，完成该范围；不要提前生成整卷。用户要求完整试卷时，连续完成全部步骤，无需逐阶段重复确认。
- 不凭空声称所有学科都存在对应的高考全国卷。要求复刻特定年份、卷别或学科时，核验对应样卷；不能取得样卷时使用明确标注的近似风格。
- 现有卷的修改保留用户指定内容与格式，重新核对受影响的答案、采分点、分值和分页。

## 1. 归整输入

汇总当前对话、附件和参考卷中已有的：学科或跨学科主题、学段与学情、考试用途、考查范围、教材或课程版本、总分、考试时长、题型/题数/分值、预计难度、必考/不考内容、版式要求。

学科和范围无法确定时，用一次简短问题补齐关键缺项。其他信息可以依据已知题型、学情和考试用途提出明确的默认值；不能默默决定会显著影响考试目标的总分或难度。范围较模糊时先整理范围边界，继续能够独立完成的工作。

用户说“难一点”时结合学情解释为可执行的预计难度分布；不把推测的得分率当成实测数据。不把作文、实验或高分题自动归为难题。

## 2. 分配考点分值

阅读 [命题蓝图规则](references/assessment-blueprint.md)。先把范围整理为知识/能力板块、核心考点和细分内容，再分配分值。

优先满足用户的硬性要求。依据考试用途、课程核心要求、内容规模和已核验样卷确定软性权重，不按教材页数或考点数量平均分配，也不虚构“官方考点权重”。考点 × 预计难度 × 题型联合安排；分值比例以可获得分值而非题目数量统计。

每一分在主要考点分布中只计一次；辅助考点和综合能力另作覆盖记录。板块分值通过小问与采分步骤归属核对。先确定完整、可行的蓝图，再出题；不是先自由出题后补标签。

蓝图放入工作记录，简要说明主要分配理由及必要假设。用户要求自动出卷时据此继续；只有无法同时满足的硬性要求才需要用户决定取舍。

## 3. 制作逐题命题方案

为每道题记录：题号、题型、分值、主要/辅助考点、考查要求、预计难度与依据、题目呈现方式、所需图表/材料、预计作答时间。大题进一步记录各小问的任务、分值、联系与评分维度。需要独立作答区时，按实际小问记录作答方式、预计手写量、估计依据、行高/格子尺寸及预留容量；同一写作任务的多个评分维度不重复留空间。解答完成后更新估计，具体结构见 [答题空间与排版组件](references/answer-space-components.md)。

检查整卷的方法重复、题目互相泄题、阅读/计算/写作总量、前问错误导致后问失去可答性的风险，以及题型排序。各学科采用合适的题型与难度安排；不一律套用数学式递进小问。

## 4. 配套生成题目与解答采分点

每道题作为一个完整单元生成并审核：题干及必要材料 → 图表与 LaTeX 公式 → 独立求解或作答 → 参考解答 → 采分点及分值。审核通过后分别进入试题卷与答案卷。

- 客观题检查答案数量、选项歧义及干扰项依据；多选题的给分规则由用户或已核验模板决定，卷首说明与答案卷一致。
- 计算、证明及实验题检查条件充分性、量纲、精度、结果和推理。生成时的首次解答还需重新核算；适用时用计算工具验证数值和图表。
- 开放题、论述和写作题区分“示例答案”与“评分标准”，明确可接受的等价表述、其他立场/方法及分档边界，不要求与参考文字完全相同。
- 作文、作品评价等按评分维度分配分值；明确总分上限及扣分是否包含在原维度中，避免重复扣分。选做题按合法作答组合计算满分。
- 材料引用保留可追溯来源。自编材料不能假托真实作者、史料、研究或官方数据；模拟实验数据在恰当位置说明。语言学科阅读材料与题目要求匹配，不捏造来源。
- 采分点写清得分条件、分值及必要的部分得分规则；小问采分点之和等于小问分值，题内小问之和等于题分。接受其他正确解法。

完成全部题目后，从实际解答和采分点反算考点、题型、难度和总分。偏离蓝图时修改题目或在软性允许范围内调整分配，不能靠更换标签掩盖偏差。预估作答时间与考试时长匹配并保留检查余量。

按参考文件中的通用 JSON 结构运行 `scripts/check_blueprint.py`：计划阶段用 `--stage plan`；最终按采分点重建后用 `--stage final`。脚本核对分值关系，不代替学科内容审查。使用环境提供的 Python，命令中的 `python` 是解释器占位，不要求安装额外包。

## 5. 生成两份 Word

阅读 [Word 排版与媒体规则](references/word-layout.md)。若当前环境提供 documents 文档技能，使用其作者工具和渲染检查流程；否则使用可用的 DOCX 工具落实这些规则。不能把 Markdown 或改名的文本文件作为 Word 交付。

默认 A4 纵向单栏、黑白、宋体小四正文、全国卷风格的标题/题号层级。支持用户提供的样卷、A3 横向双栏和其他纸张；保持用户版式优先。按实际学科排阅读材料、公式、地图、实验图、表格、写作区域和采分点。使用 Python 作者工具时，优先复用 `scripts/word_components.py` 的空白、横线、作文格、绘图区与选项组件；按上述组件参考调用，不用重新堆空行、空格或下划线。用户模板需要其他实现时保持模板优先并落实相同宽度、容量及核验规则。

- 数理图表可用代码准确绘制或合适的 Word 原生图表/形状；数据表优先用原生表格。
- 数学、物理、化学等公式统一以 LaTeX 表达。优先走经过验证的转换路径生成可编辑 Word 公式；复杂或不支持的表达采用可靠渲染时说明其图片属性。保留公式源，不声称图片可以像 Word 公式一样编辑。
- 试题卷不含答案、采分点或命题标签，包括图层、批注、隐藏文字及图片中的答案线索。
- 每道大题依据实际手写步骤和作图需求留白；不按分值等比例硬分空间，不靠连续空行凑页。题目与答题区域共同参与分页，不强行压缩字号。多行作答横线按排版参考中的“作答横线”规则生成，延伸至作答区的可用右边界，不用重复下划线字符拼接。
- 普通内容自然跨页，不为阅读材料、题目或作答区增加“续”“续题”“作答续”等重复标题；跨页表格可保留必要的“续表”和重复表头。
- 按排版参考中的编号规则区分大题、分块、独立试题、小问、选项、材料和图表的编号层级与范围；同类格式统一，两卷及引用共用题号对应关系，增删或调序后检查重复、跳号、漏号及换行对齐。
- 答案卷按相同题号排列，给出完整解答与逐项采分点；不留考试作答空白。共用图表信息，必要时另制教师用解释图，防止流入学生卷。

## 6. 验证与交付

同时进行内容/分值检查和页面检查。把最终 DOCX 渲染为逐页图片并查看全部页面，修正公式缺字/裁切、图表模糊、题干与配图分离、选项错位、采分点分值错位、答题区域不足和不合理分页后重新渲染。空白答题区是必要内容，不因其空白而删去。将渲染后的实际作答容量记回各题的 `answer_spaces`，与预计手写量及预留容量比较；完整试卷运行 `scripts/answer_space.py work/blueprint.json --stage final` 核对容量记录。组件配置值不能代替页面测量，空间不足时增加作答区并重新分页、渲染。

依据排版参考中的“字体设置与保存后核查”，检查最终保存后的实际字体和符号字形来源；页面看起来相似不代表字体正确。发现主题覆盖或未声明的字体替换，修正后重新保存、核查和渲染。

若环境缺少可靠渲染器，保留 DOCX，尝试现有可用的预览路径；最终明确说明未完成页面核验，不能声称已全部检查或静默交付为已验证成品。若缺少必要的内容来源、图形工具或公式支持，说明具体影响，完成不受影响部分。

默认只交付两份最终 Word 文档，简述采用的分配、预计难度和重要偏差。命题蓝图、原始公式、图源和页面预览保留在工作目录；用户要求时再提供。不要把作者工具、内部标签和核验说明塞入学生卷。

## 使用示例

“使用 $exam-paper-word，制作一份高中历史试卷，范围为近代中国史，满分100分，选择题40分、材料分析题60分，预计难度中等，大题留足作答空间。”

“使用 $exam-paper-word，制作一份小学英语单元检测，按附件教材确定范围和题型，分别输出试题与答案评分标准。”

示例不限制学科、学段、总分或题型；实际请求始终优先。
