# Word 排版与媒体规则

## 版式的性质与优先级

用户模板/明确设置 → 已核验的指定年份学科样卷 → 本技能默认参数。

默认追求全国卷的正式、黑白、层级清楚的风格，但数值属于此技能的设置，不是全国卷官方排版规范。直接作答留白会改变真题式紧凑分页；不要强求原卷页数。不同学科、学段和无对应全国卷的课程采用相同视觉原则及适合本学科的结构。

## 默认页面与字体

| 内容 | 设置 |
|---|---|
| 纸张 | A4纵向，单栏 |
| 页边距 | 上下左右各2厘米；装订需求另行调整 |
| 主标题 | 宋体加粗，15磅（小三），居中 |
| 学科名称 | 黑体，16磅（三号），居中 |
| 时间、满分、考生信息 | 宋体，10.5—12磅 |
| 大题标题及题型说明 | 宋体，12磅（小四）；标题部分加粗 |
| 题干、选项、小问、答案正文 | 宋体，12磅 |
| 英文、普通数字 | Times New Roman，与正文等大 |
| Word数学公式 | 可用Cambria Math等适合的数学字体，与正文视觉等大 |
| 表格、图中标签 | 原则上10.5—12磅；实际打印尺寸检查 |
| 页脚 | 宋体，10.5磅，居中“××试题 第X页 共Y页” |
| 行距 | 普通正文1.25倍；公式及特殊内容段落允许增高 |
| 颜色 | 黑白；图表可用灰阶、线型和纹理区别 |

用样式控制字体、题号、缩进及段落间距，设置中文和西文字体，避免仅设置西文字体导致中文继承主题字体。字体不可用时寻找适合替代并说明差异，不静默换成完全不同的默认字体。

### 字体设置与保存后核查

- 在 DOCX 中指定字体时，清除相应 `w:rFonts` 的 `asciiTheme`、`hAnsiTheme`、`eastAsiaTheme`、`cstheme` 等主题覆盖，再显式设置中文、拉丁及复杂文字所需字体。正文、标题、表格、页码域、超链接和空白作答区的段落标记均需检查；只改可见文字可能仍留下不同的输入字体。
- 设置中文语言及主题东亚语言为本卷需要的语言（简体中文通常为 `zh-CN`），避免标题按其他语言的主题字体解析。指定科目名称的黑体时，确认实际应用到该段，不只写在设计说明中。
- 字体分工按字形覆盖落实。Times New Roman 不含常用圈号字形时，将圈号明确设为宋体等具有该字形的已验证字体；遇到罕见汉字、音标、数学符号或其他文字，同样核查其实际字形来源，不能依赖自动替换来凑齐。此规则不限制其他学科使用适合的专用字体。
- 在 Word 或其他目标渲染器保存、更新域之后，再检查最终文件的有效样式与实际使用字体；重新渲染并检查标题、符号及分页。字体表中出现某字体只能作为排查线索，不能据此断定它已用于正文；必要时结合字形/文本范围和渲染结果定位。发现非设计字体时修正并重新核验。
- 指定字体在目标保存/渲染路径发生替换时，先修正来源样式与排版设置；仍不能可靠落实时，明确说明受影响的文字，并采用用户约定或已说明的替代方案。不得把仅有字体名称、实际发生替换的结果标记为已核验。单份试卷的兼容处理不应改写其他学科的默认字体分工。

用户选择A3横向双栏时，重新计算栏宽、栏间距、图表尺寸和分页。不要简单把A4文档纸张改大；也不要混淆A3双栏与A4拼页的印刷顺序。默认不强加密封线、装订文字、题目得分总表或“绝密”等卷首内容，用户/参考模板需要时添加。

## 卷首、题号与选项

- 标题真实描述本次考试，不把自编试卷冒称正式高考真题。写明科目、时间、满分及必要考生信息。
- 作答说明与实际方式一致：直接在卷上作答时不能沿用“在试卷上作答无效”的答题卡说明。多选、选做、作文字数等规则要说明清楚。
- 在命题记录中确定各类编号的层级、格式和起止范围，按下文编号规则排版；用户模板或学科惯例优先。
- 大题说明写清题数、分值和必要规则。没有题型需要时不硬拆成选择、填空、解答三部分。
- 选项按宽度选择一行四项、两行两项或每项一行。用制表位或可靠的无边框选项布局对齐，不用反复插入空格凑位置。不得把复杂选项挤得过窄。
- 题号使用悬挂缩进使长题干续行自然对齐。阅读材料保留段落结构，避免为了省页破坏材料。

### 编号层级与适用范围

以下为中文试卷的默认方案；其他语言、学科或指定样卷有不同惯例时，先选定方案，再全卷统一。只启用实际需要的层级，不为凑层级增加标题。

| 类别 | 默认格式 | 编号范围 |
|---|---|---|
| 大题或主要板块 | 一、二、三、 | 按板块顺序递增 |
| 大题内的分块 | （一）（二）（三） | 在所属大题内递增；没有分块时省略 |
| 独立试题 | 1．2．3． | 全卷连续，不因换板块或跨页重新从1开始 |
| 题内小问 | （1）（2）（3） | 每道题内从（1）开始 |
| 小问内的进一步细项 | ①②③ | 仅在需要时使用，在所属小问内编号 |
| 选择题选项 | A．B．C．D． | 每道选择题从A开始；选项数量按题型决定 |
| 阅读或分析材料 | 材料一、材料二；或文本一、文本二 | 同一材料组使用同一种称呼，在组内编号 |
| 注释 | ①②③ | 每篇材料独立编号，注号与注释一一对应 |
| 图和表 | 图1、图2；表1、表2 | 图、表分别连续编号；采用题内编号时，跨题引用须带题号 |

- 不同层级使用可区分的格式，例如“一、阅读”下设“（一）信息性阅读”，避免上下两级都写成“一”。同一层级的句点、顿号、括号、大小写及全角/半角统一，不混用“1．”“1.”“（1）”，也不混用“A．”“A.”“（A）”。
- 卷首注意事项的编号独立于试题编号；材料段落、注释、图表、选项及答案采分步骤也有各自的范围。不要让 Word 自动列表把这些不同序列串在一起。注释与细项虽然均可使用圈号，应靠所属段落和“【注】”标识区分；同处出现歧义时改用明确标签。
- 编号从同一份题目记录生成，试题卷、答案卷、评分标准、答题区标签和“完成第几至第几题”等引用共用同一对应关系。题目增删或调序后更新全部相关编号与引用；答案卷保留题内小问编号，不另起一套容易混淆的题号。
- 使用分层样式、独立的列表序列或可靠的显式编号。采用自动编号时明确续接和重启规则，保存后检查有无意外重编号；采用显式编号时检查有无漏改。跨页只延续正常编号，不添加“续题”标题。
- 按实际编号宽度安排悬挂缩进与制表位，让两位数题号、括号小问和选项的换行正文对齐；不用堆空格对齐。题号与题干、选项字母与选项内容、小问编号与对应作答区保持关联，避免编号孤立在页末。
- 保留引用材料自身有意义的章节、段落及原有编号，不把它们误当成试题编号重排。需要加段落序号便于设问时，明确其为命题添加的定位标记；公式编号、图中点名等按学科惯例处理，与题号分别管理。

最终同时核对结构与页面：独立试题无意外重复、跳号或漏号；各小问和选项在正确范围内重启且连续；材料注号、图表号和题目范围引用有效；两卷逐题逐小问对应；编号符号、字形、对齐及跨页位置正确。用户指定的非连续题号或选做编号保留，并明确检查其对应关系。

## 图形、图表与表格

- 函数图、几何图、统计图、实验曲线等根据同一数据/参数记录绘制，优先精确代码或合适的Word原生图表/形状。代码生成科学图形不需要调用艺术图像生成工具。
- 图形满足题干条件；坐标、刻度、单位、点名、实虚线、图例完整。示意图不强行伪装为精确比例图，必要时在题中注明。
- 地图、历史材料图、作品图及其他学科图按其领域规则处理；需要真实参考图时使用可追溯素材，不自行伪造史料或作品出处。
- 图像选择支持的矢量格式或足够分辨率的位图，按实际插入尺寸检查标签清晰度、裁切和线宽；不拉伸比例。位图一般以实际印刷尺寸约300dpi作为起点。
- 学生图只呈现应给的信息，教师解释图可增加辅助线与答案标注；二者明确分开。
- 数据表优先Word原生表格。表头、单位和数值与题干、解答同源；允许需要的空白填写格。
- 黑色细表格线和简洁表头；按内容确定列宽，允许行高随内容增长，避免固定行高裁字。不要把全部题干或全部答案塞进带框表格。
- 图表尽量与设问同页，使用可靠的嵌入式定位；小图旁排时检查阅读顺序，较大图单独占行。重要图表的尺寸优先于硬凑页数。

## LaTeX 与 Word 公式

- 所有数学表达（包括题干、选项、图中标签、解答和采分点）以LaTeX作为源；普通文本中的题号、日期和分值无须转换为公式。
- 区分行内和独立公式。独立公式居中，行内公式基线与正文协调。变量、上下标、单位和特殊符号全卷统一。
- 优先经测试的LaTeX→Word原生数学公式（OMML）路径；验证转换后分式、根号、矩阵、分段、上下标等结构。不能仅插入LaTeX命令文本并声称排成公式。
- 无可靠原生转换支持时，可将LaTeX通过MathJax或其他可靠工具渲染成清晰图形；说明这是公式图片并保留源，不冒称可编辑数学对象。若用户要求必须可编辑，说明具体障碍，不以图片静默替代。
- 化学反应式等使用工具支持的LaTeX表达或经验证的宏包路径。未支持的命令先处理，不把未知宏命令留在文档中。
- 不要求另建独立.tex文档或打开LaTeX编辑器；LaTeX是公式来源，最终成果仍是两份.docx。
- 公式段落不用会裁切高分式的固定行距。渲染后检查基线、字号、缺字、模糊、裁切及不合适换行。

## 按实际书写量留白

1. 根据完整解答和实际作答宽度估计学生手写行数，而不是直接采用教师答案的排版行数。多行公式、大分式、分类讨论需更高空间。按 [答题空间记录与组件](answer-space-components.md) 为实际小问记录估计依据、空间类型和容量，解答或栏宽改变后更新；不按评分维度重复生成同一作答区。
2. 默认把每行手写所需高度约8—10毫米作为初始估计，根据学段、书写类型和用户要求调整；为推导与改写留适当余量。该估计不是保证，须页面检查。
3. 按实际作答方式选择区域，不能只凭“简答题”等题型名称加线。数学计算、推导、证明默认留连续空白；作图题另加绘图区或所需坐标框；文字简答/论述按学科习惯可加横线；写作题按字数与学科习惯准备格子或横线。不能把中文作文格统一用于外语写作。
4. 通过可控高度的答题区安排空间，不用几十个空行凑版面。优先复用 `scripts/word_components.py`，调用方法与依赖见上述组件参考。若采用答题区表格，保持无多余边框、最小行高、合理跨页设置，避免固定高度裁切。按预计手写行数与余量计算高度，绘图区单独计入；作文格按可用格数核算字数容量。
5. 题干、小问和答题空间联合分页。页末只剩题号/一行题干或无法书写时，整体移到下一页。
6. 长题可在自然小问边界分开，保留正常题号和小问编号；不要把整个超长题设置成永不分页而产生溢出。普通正文、阅读材料、题目和作答区自然跨页，不添加“续”“续题”“作答续”等重复页首标题或提示。跨页表格可按需要保留“续表”和重复表头。
7. 不按题分机械分配相同空间，不缩小正文补足页数。必要空白是考试功能，不是排版缺陷。渲染后记录实际可写高度、宽度及行/格数；跨页只累计真正可作答的页段。发现配置与实际容量不符或书写量超出容量时修正，不把脚本的算术通过当作页面合格。

### 作答横线

- 区分题干中的短填空线与多行作答横线。短填空线按预期答案长度和题干布局安排，不要求铺满整行；以下宽度规则用于简答、论述、写作等多行作答区。
- 多行作答横线不得靠重复输入下划线字符（`_`）拼接，也不靠给一串空格加下划线凑宽度。采用按作答区宽度定义的线条，例如仅保留横向边框的单列表格；也可使用经渲染验证的独立段落下边框，须防止相邻段落边框合并成一条线。
- 根据当前节的纸张、页边距、分栏、作答区左右缩进及容器内边距确定横线起止位置。横线延伸至作答区的可用右边界，同一作答区各行左右端对齐；不把整页宽度当成栏宽，也不因继承题号或题干缩进而无意缩短横线。用户指定窄作答区时按指定宽度处理。
- 线间距按预计手写行高设置，横线数量按实际作答量确定。表格方案显式设置宽度并关闭按内容自动调整，检查单元格边距与边框位置；保持黑色细线，不增加左右外框或其他多余边框。
- 渲染后检查每条线是否到达预定右边界、同一区域各行是否等长，有无意外折行、短尾线、边框合并或跨页丢线。页边距、分栏、缩进或表格宽度调整后重新计算并检查，不能只凭下划线字符数量或文档中的宽度设置判定合格。

## 答案与评分标准

相同题号与小问次序。客观题可用紧凑答案表；主观题按解答过程给出得分条件和分值。分值使用可靠的制表位或单独段落标注，避免多空格对齐。作文和开放题给出维度、档次与适当的示例，不强迫逐字匹配。

保持与试题卷相同的图表数据、符号和术语。必要的教师解释图单独标识。答案卷使用自然分页，不保留学生答题区；不要为了压缩页数大量减小字体。

## 双重核验

结构/内容：题序和小问对应；卷面各分值合计；采分点合计；主分值不重复；合法选做组合；题型与难度要求；材料来源；题目正确性；题干与图表一致；学生卷中没有答案泄漏。

页面：用当前环境提供的DOCX渲染工具输出逐页图像，查看全部页面。核对字体、标题、页码总数、题目分页、选项、公式、图表、表格及各答题区；有多行作答横线时，检查线宽、左右端对齐、线间距和跨页显示。修正后重新渲染最终版本。结构检查通过不等于页面检查通过。

若当前环境提供工作区依赖加载工具，通过它取得文档工具与解释器路径；不要将本机特定版本路径写死为技能要求。优先使用文档技能自带的渲染器和依赖，不额外安装系统办公软件来替代。缺失或失败时保留文档并如实报告核验状态。
